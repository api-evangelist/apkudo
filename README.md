# Apkudo

Apkudo operates the Device Passport Platform for the connected device supply chain, combining
software, AI and advanced robotics to capture trusted data at every stage of a device's life —
Launch (certification and testing), Trade In, Recover (enterprise asset recovery), Process
(automated functional and cosmetic grading) and Monetize. Headquartered in Baltimore, Maryland,
with offices in Dallas, Flensburg (Germany) and Sydney.

- Website: https://www.apkudo.com/
- Platform overview: https://www.apkudo.com/platform-overview
- Diagnostic SDK: https://www.apkudo.com/diagnostic-sdk
- Trust center: https://apkudo.trustcenter.sprinto.com/
- Secondary market listing: https://forgeglobal.com/apkudo_stock/

## API surface

Apkudo publishes **no public developer program**. As of 2026-08-02 there is no developer portal,
no API reference, no OpenAPI/AsyncAPI/GraphQL/MCP contract, no `/.well-known/` discovery surface
and no client library in any public package registry. Apkudo does document API and SDK
integration as a commercial capability — the Diagnostic SDK is a real first-party client library
distributed to carriers, OEMs, retailers and logistics partners under agreement rather than
through a registry.

See `well-known/apkudo-well-known.yml` for the full contract-discovery probe record, including
every host and path checked and its HTTP status.
